#Esercizi esama Linguaggi dell'Intelligenza Artificiale
Questo repository raccoglie gli esercizi e i progetti pratici svolti per la preparazione all'esame di **Linguaggi dell'Intelligenza Artificiale**. 
Il codice è sviluppato principalmente utilizzando due paradigmi di programmazione fondamentali per l'AI: la programmazione funzionale e la programmazione logica.
Linguaggi di programmazione utilizzati: Haskell e Prolog.
